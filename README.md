# ONEFLOW PRO BUSINESS — מחשבון אומדן

מחשבון אומדן עלויות למיישמים. אתר סטטי, ללא שרת וללא בסיס נתונים.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | המחשבון כולו |
| `pricing.json` | **המחירון הרשמי** — מה שרואה מי שנכנס בלי קישור אישי |
| `pricing-<שם>.json` | מחירון אישי של מיישם |
| `logo.png` | הלוגו הראשי בכותרת ובמסמך המופק |
| `oneflowlogo.png` | לוגו המוצר, מוצג במסמך המופק |

## מחירון לכל מיישם

לכל מיישם קישור אישי, והוא טוען את קובץ המחירון שלו:

```
https://<כתובת-האתר>/?p=moshe   ->   pricing-moshe.json
https://<כתובת-האתר>/?p=dana    ->   pricing-dana.json
https://<כתובת-האתר>/           ->   pricing.json  (המחירון הרשמי)
```

המזהה בקישור מסונן לאותיות אנגליות קטנות, ספרות, מקף וקו תחתון בלבד.

### להקים מחירון למיישם חדש

1. פתח את המחשבון, היכנס להגדרות (גלגל השיניים) וערוך את המחירים.
2. לחץ **ייצא** — יורד קובץ JSON.
3. שנה את שמו ל-`pricing-<שם>.json` והעלה אותו לתיקייה הראשית של הפרויקט.
4. שלח למיישם את הקישור `?p=<שם>`.

שדות שכדאי למלא בקובץ:

| שדה | תפקיד |
|---|---|
| `label` | שם המחירון, מוצג בכותרת ובמסך ההגדרות |
| `implementerName` | שם המיישם, ממולא אוטומטית באומדן |
| `publishedAt` | חותמת תאריך, נוצרת אוטומטית בייצוא |

### לעדכן מחירון קיים

ערוך, ייצא, והחלף את הקובץ הקיים. המיישם מקבל את העדכון בפתיחה הבאה —
הקובץ נטען ללא מטמון.

## שינוי מקומי אצל מיישם

מיישם שעורך מחירים במסך ההגדרות יוצר **עותק מקומי** בדפדפן שלו בלבד.
התגית בכותרת מתחלפת ל־"מחירון מקומי", וכפתור במסך ההגדרות מחזיר אותו
למחירון שמגיע מהקישור. העותק המקומי אינו מגיע לאף אחד אחר ואינו עובר
בין מכשירים.

## מודל התמחור

- **תמיכה ותחזוקה** — סכום חודשי לכל מודול נבחר.
- **מענק הקמה** — מכסת טרנזקציות חד-פעמית לכל מודול, ללא עלות.
- **חבילת טרנזקציות** — המכסה החודשית בפועל, נרכשת בנפרד.
- **משתמשים** — מכסה כלולה, וחבילות נוספות בתשלום.
- **הקמה** — סך שעות ההקמה של המודולים כפול תעריף השעה.
- **מינימום חיוב חודשי** — אומדן שנופל מתחתיו מחויב בסכום המינימום.

## פיתוח

אין תהליך בנייה. הקובץ `index.html` נטען ישירות בדפדפן ומקמפל JSX
בזמן ריצה. לצפייה מקומית יש להגיש את התיקייה דרך שרת HTTP פשוט —
פתיחה ישירה מהדיסק תמנע את טעינת קובץ המחירון.
